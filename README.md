# Backend приложения для социальной сети обмена фотографиями

## Описание проекта
Данный проект представляет собой backend социальной сети для обмена фотографиями, разработанный на Django и Django REST Framework.

Пользователи могут:
- создавать публикации с текстом и фотографией;
- просматривать публикации;
- оставлять комментарии;
- ставить и удалять лайки.

## Стек технологий
- Python 3.11
- Django
- Django REST Framework
- PostgreSQL
- Pillow
