# 📸 Pixshare — социальная сеть для обмена фотографиями

## 📌 Описание проекта

Pixshare — это веб-приложение, реализующее базовый функционал социальной сети для публикации фотографий.

Проект разработан на Django и Django REST Framework и демонстрирует полный цикл работы пользователя от регистрации до взаимодействия с контентом.

---

## ⚙️ Технологии

- Python 3.11
- Django
- Django REST Framework
- SQLite
- HTML / CSS (Django templates)

---

## 🚀 Функциональность

Пользователь может:

- зарегистрироваться и войти в систему
- создавать посты с изображениями
- просматривать ленту публикаций
- ставить лайки
- оставлять комментарии
- удалять свои посты (только автор)

---

## 🔐 Авторизация

- реализована регистрация пользователей
- вход и выход из системы
- разграничение прав доступа

---

## 🖥️ Интерфейс

Frontend реализован с использованием шаблонов Django.

- главная страница — лента постов
- страница поста — комментарии и лайки
- форма создания поста
- регистрация и вход

---

## 📂 Структура проекта

config/     — настройки Django (settings, urls)
posts/      — бизнес-логика (модели Post, Comment, Like)
frontend/   — интерфейс (views, forms, templates)
media/      — загруженные изображения


Проект построен по модульному принципу.
Бизнес-логика и модели вынесены в отдельное приложение posts,
а пользовательский интерфейс реализован в отдельном модуле frontend,
что обеспечивает разделение ответственности и упрощает масштабирование системы.
