# Pixshare - социальная сеть для обмена фотографиями

## Описание проекта

Pixshare - это веб-приложение социальной сети для обмена фотографиями. Проект разработан в рамках дипломной работы по направлению Python-разработки.

Приложение позволяет пользователям регистрироваться, входить в систему, создавать публикации с изображениями, редактировать и удалять собственные посты, оставлять комментарии и ставить лайки.

## Стек технологий

- Python 3.11
- Django
- Django REST Framework
- PostgreSQL
- HTML / CSS (Django templates)
- JavaScript
- Git / GitHub
- Postman

## Основной функционал

- регистрация нового пользователя;
- вход и выход из системы;
- создание поста с названием, текстом и изображением;
- отображение ленты публикаций;
- просмотр отдельного поста;
- редактирование поста только автором;
- удаление поста только автором;
- добавление комментариев;
- ограниченный вывод длинных комментариев с возможностью раскрытия полного текста;
- постановка и удаление лайков;
- предпросмотр изображения при создании и редактировании поста;
- модальное открытие изображения;
- кнопка возврата наверх страницы;
- уведомления о действиях пользователя.

## Безопасность

В проекте реализованы:

- хэширование паролей средствами Django;
- валидация пароля при регистрации;
- CSRF-защита форм;
- разграничение прав доступа;
- запрет редактирования и удаления чужих постов;
- авторизация для создания постов, комментариев и лайков.

## Структура проекта

```text
config/       - настройки Django-проекта
posts/        - модели, сериализаторы и API для постов, комментариев и лайков
frontend/     - пользовательский интерфейс: views, forms, urls, templates
media/        - загруженные пользователями изображения

REST API

В проекте реализован REST API на Django REST Framework.

Основные API-эндпоинты:

POST /api/token/                     — получение токена авторизации
GET  /api/posts/                     — список постов
POST /api/posts/                     — создание поста
GET  /api/posts/<id>/                — просмотр одного поста
PUT/PATCH /api/posts/<id>/           — редактирование поста
DELETE /api/posts/<id>/              — удаление поста
POST /api/posts/<id>/comments/       — добавление комментария
POST /api/posts/<id>/like/           — поставить лайк
DELETE /api/posts/<id>/like/         — убрать лайк
Пользовательский интерфейс

Frontend реализован с использованием Django templates, HTML, CSS и JavaScript.

В интерфейсе реализованы:

современный дизайн карточек публикаций;
уменьшенный размер изображений в ленте;
модальное открытие изображений;
предпросмотр изображения перед публикацией;
счётчик символов для названия поста;
раскрытие длинных комментариев;
подтверждение удаления поста;
кнопка возврата к началу страницы.
Установка и запуск проекта
1. Клонировать репозиторий
git clone https://github.com/elmiramiro/Pixshare.git
cd Pixshare
2. Создать виртуальное окружение
python -m venv venv
3. Активировать виртуальное окружение

Для Windows:

venv\Scripts\activate
4. Установить зависимости
pip install -r requirements.txt
5. Создать базу данных PostgreSQL

Создайте базу данных PostgreSQL и укажите параметры подключения в файле config/settings.py.

Пример настройки:

DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.postgresql',
        'NAME': 'pixshare_db',
        'USER': 'postgres',
        'PASSWORD': 'your_password',
        'HOST': 'localhost',
        'PORT': '5432',
    }
}
6. Применить миграции
python manage.py makemigrations
python manage.py migrate
7. Создать суперпользователя
python manage.py createsuperuser
8. Запустить сервер
python manage.py runserver
9. Открыть приложение
http://127.0.0.1:8000/

Админ-панель:

http://127.0.0.1:8000/admin/
Основные страницы

/create/                  — создание поста

/posts/<id>/edit/         — редактирование поста
